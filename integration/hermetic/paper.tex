\begin{abstract}
This document was typeset by a \texttt{pdflatex} that Bazel downloaded, not by
one installed on the machine. The engine, the PDF utilities and every
\texttt{.sty} file it read are declared inputs of the build action.
\end{abstract}

\section{How the tools are resolved}

The \texttt{latex\_document} rule names no binary. It depends on
\texttt{//latex:toolchain\_type}, and toolchain resolution picks whichever
implementation the root module registered.
